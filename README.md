# 🦊 FoxEnglish Telegram Bot

Телеграм-бот для записи пользователей на бесплатные онлайн-занятия по английскому языку.

## ✨ Возможности
✅ Запись пользователя на занятие  
✅ Выбор дня и времени  
✅ Хранение информации в базе `SQLite`  
✅ Админ-уведомления о новых записях  
✅ Команда `/mybookings` — просмотр своих записей  
✅ Автоматические напоминания за 24 часа и за 3 часа  

## ⚙️ Установка

### 1️⃣ Установка зависимостей
```bash
pip install -r requirements.txt
```

### 2️⃣ Создай `.env` файл
```env
BOT_TOKEN=1234567890:ABCDEF1234567890abcdef
ADMIN_CHAT_ID=123456789
DB_PATH=bookings.db
CAPACITY=10
```

### 3️⃣ Запуск бота
```bash
python bot.py
```

## ☁️ Деплой на Bothost
1. Создай репозиторий на GitHub.
2. Залей туда `bot.py`, `requirements.txt`, `README.md` и `.env.example`.
3. Подключи репозиторий на Bothost.
4. Добавь переменные окружения вручную (из `.env`).
5. Укажи команду запуска:
```bash
python bot.py
```
